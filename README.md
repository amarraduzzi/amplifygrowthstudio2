# amplifygrowthstudio.com

Bedrijfssite van Amplify Growth Studio. Astro + Tailwind, statisch, Cloudflare Pages.

- `npm install` en `npm run dev` (lokaal), `npm run build` (naar `dist/`)
- Cloudflare Pages: build command `npm run build`, output `dist`
- Teksten: `src/i18n/fr.ts`. Contactgegevens en domein: `src/config.ts`
- Zolang `live: false` staat de site op noindex.
- Open punten: zie `OPEN-PUNTEN.md`
